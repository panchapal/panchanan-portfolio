# Panchanan Pal | Frontend Developer Portfolio

A modern, interactive portfolio website built with HTML, CSS, and JavaScript — featuring a glassmorphism UI, animated constellation particle-network background, and smooth scroll-driven reveal animations.

![Portfolio Preview](https://panchanan-portfolio.vercel.app/)

🔗 **Live Demo:** [https://panchanan-portfolio.vercel.app/]

---

## ✨ Features

- **Interactive Background** – Animated constellation particle network that reacts to mouse movement and clicks, with multiple density modes (Normal, Dense, Galaxy, Subtle)
- **Dark/Light Theme Toggle** – Seamless switching between dark and light modes
- **Glassmorphism Design** – Frosted-glass panels with glowing accents and smooth hover transitions
- **Fully Responsive** – Optimized layouts for desktop, tablet, and mobile, including a mobile navigation drawer
- **Scroll-Driven Animations** – Native CSS scroll-timeline animations with an IntersectionObserver fallback for older browsers
- **Sections Included:**
  - Hero / Introduction
  - About Me with stats
  - Technical Skills
  - Case Studies / Recent Work (with project screenshots)
  - Education & Training Timeline
  - Contact Form with toast notifications

---

## 🛠️ Built With

- HTML5
- CSS3 (Custom Properties, Glassmorphism, Scroll-driven Animations)
- Vanilla JavaScript (Canvas API for particle animation)
- [Font Awesome](https://fontawesome.com/) for icons
- Google Fonts – Outfit & Syne
